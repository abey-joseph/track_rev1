# core — CONTEXT

Cross-cutting infrastructure shared by all features. Domain layers must not import anything Firebase/Drift-specific from here; only `error/`, `usecases/`, `constants/`, and `extensions/` are domain-safe.

## Subsections

### `config/`
- `env.dart` — `@Envied` Firebase keys loaded from `.env` (obfuscated). Part file: `env.g.dart`.

### `constants/`
- `app_constants.dart` — `AppConstants` (appName, envKey, dev/prod/mock env strings, mockUserId) + `AppEnvironment.current`/`isMock`. Set `AppEnvironment.current` once in `main()` before DI.
- `storage_constants.dart` — secure-storage keys (authToken, refreshToken, userId, themeMode).
- `animation_constants.dart` — fast/default/slow/stagger durations and curves.

### `database/` (Drift, SQLite, local-first)
- `app_database.dart` — `AppDatabase` (schemaVersion **7**), tables: Habits, HabitLogs, HabitStreaks, Accounts, Categories, Transactions, RecurringTransactions, Budgets, Currencies, Insights, UserSettings. Seeds default categories on create + `Transfer` category on v6→v7. Migrations add columns per version.
- `database_module.dart` — `@preResolve @lazySingleton` `AppDatabase` from `path_provider` docs dir. DB name toggles on `AppEnvironment.isMock` (`track_mock.db` vs `track.db`). `PRAGMA foreign_keys = ON` is set.
- `daos/` — `HabitsDao`, `MoneyDao`, `InsightsDao`, `SettingsDao`. DAOs own streak recalculation, transfer pairing, recurring-occurrence generation, FX conversion, etc.
- `tables/` — 11 Drift table definitions. Transactions carry `originalCurrencyCode`/`originalAmountCents` alongside converted `amount` (cents).

### `di/`
- `register_module.dart` — third-party singletons: `FirebaseAuth`, `FlutterSecureStorage`, `Connectivity`.
- Entry point lives at `lib/injection.dart` (`configureDependencies(env)`); code is generated into `injection.config.dart`.

### `error/`
- `failures.dart` — `@freezed sealed Failure` with `server` / `cache` / `network` / `auth` / `unexpected` variants. All repo methods return `Either<Failure, T>`.
- `exceptions.dart` — `ServerException` / `CacheException` / `NetworkException`. Thrown in data layer, caught in repo impls and mapped to `Failure`.

### `extensions/`
- `context_extensions.dart` — `BuildContextX`: `theme`, `textTheme`, `colorScheme`, `mediaQuery`, `screenSize/Width/Height`, `showSnackBar(msg, isError)`.

### `network/`
- `api_constants.dart` — HTTP timeouts/base URLs.
- `dio_client.dart` — `@module` that builds a `Dio` with `TalkerDioLogger`.
- `network_info.dart` — `NetworkInfo` abstract + impl wrapping `Connectivity`.

### `router/`
- `app_router.dart` — `@AutoRouterConfig(replaceInRouteName: 'Page,Route') @lazySingleton AppRouter`. Routes: `SplashRoute` (initial) → `LoginRoute` → `AppShellRoute` (authGuarded) with 4 tabs (`DashboardRoute`, `HabitsRoute`, `MoneyRoute`, `InsightsRoute`). All habit/money create-edit routes are `CustomRoute` + `fullscreenDialog` + `slideBottom`. Detail routes use `/habit/:id`, `/transaction/:id`, `/account/:id`, `/insight/:id`, `/budget/:id`, `/habit/:id/stats`.
- `auth_guard.dart` — `AuthGuard` reads `AuthRepository.currentUser`; redirects to `LoginRoute` when null.
- Generated file: `app_router.gr.dart` — regenerated by `make gen`.

### `theme/`
- `app_theme.dart` — M3 `lightTheme`/`darkTheme` from `AppColors.primarySeed`. Global button minSize `(∞, 48)` with 12px radius. Input decoration is outlined + filled.
- `app_colors.dart` — seed colors.
- `app_typography.dart` — `textTheme`.

### `usecases/`
- `usecase.dart` — abstract `UseCase<Type,Params>` (`Future<Either<Failure,Type>> call(Params)`) and `StreamUseCase<Type,Params>`. `NoParams extends Equatable`.

### `utils/`
- `input_validators.dart` — `email`, `password` (min 8 chars), `required`.
- `logger.dart` — `@module` exposing `Talker` + `TalkerDioLogger`. `TalkerBlocObserver` is wired in `main.dart` via `Bloc.observer`.

### `widgets/`
- `app_button.dart`, `app_error_widget.dart`, `app_loading_indicator.dart`, `skeleton_card.dart` — shared primitive widgets.

## Gotchas
- Drift schema is **v7**. Any new column/table needs a bump + migration branch in `AppDatabase.migration.onUpgrade`.
- `_seedDefaultCategories` runs on fresh installs only; `_seedTransferCategory` runs on create **and** on v6→v7 upgrade.
- `@preResolve` on `database` getter means DI init (`configureDependencies`) awaits the DB — anything reading the DB during startup is safe.
- `Failure.cache` is reused to signal business constraints (e.g. deleting an in-use currency).
- Transaction entity has **two** amount pairs: `amountCents`/`originalAmountCents`. FX conversion happens in the money DAO, not in BLoCs.
